# 🌾 Agri-Assist Village

Agri-Assist Village is a Progressive Web Application (PWA) built using React, TypeScript, and Tailwind CSS. It helps farmers with modern agricultural solutions.

## Features

- 🌦️ Weather Forecast
- 🪲 Plant Disease Detection
- 💰 Crop Price Prediction
- 🛒 Farmer Marketplace
- 👨‍🌾 Labour Hiring
- 🌐 Multilingual Support
- 📱 Mobile Friendly
- 📶 Offline Support

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Installation

```bash
npm install
npm run dev
